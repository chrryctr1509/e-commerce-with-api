# E-Commerce with API

A full-stack e-commerce application with API integration.

## Tech Stack
- Frontend: HTML / CSS / JavaScript
- Backend: REST API
- Database: MySQL / MongoDB

## Features
- Product listing
- Shopping cart
- Order management
- API integration
- User authentication

## Getting Started

### Installation
```bash
git clone https://github.com/ErisBackend/e-commerce-with-api
cd e-commerce-with-api
npm install
```

### Configuration
```bash
cp .env.example .env
# Edit .env with your API credentials
```

### Run
```bash
npm start
```

## API Endpoints
| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | /api/products | Get all products |
| POST | /api/cart | Add to cart |
| GET | /api/orders | Get orders |
